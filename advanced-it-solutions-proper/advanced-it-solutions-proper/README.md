# ADVANCED IT SOLUTIONS
Digital Access. Smarter Solutions.

Complete enterprise e-commerce and digital services marketplace platform.

## Quick Deployment Steps:
1. Extract this ZIP file.
2. Ensure your Supabase/PostgreSQL database tables are initialized using the provided Prisma schema.
3. Push the repository to GitHub.
4. Import into Vercel and configure your Environment Variables (`DATABASE_URL`, `ENCRYPTION_MASTER_KEY`, `SESSION_SECRET`).
